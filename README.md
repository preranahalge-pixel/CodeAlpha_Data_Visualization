# CodeAlpha Task 3: Superstore Sales Data Visualization

## Project Overview
This project visualizes Superstore sales data using Python to explore sales trends, product performance, regional sales, customer segments, and shipping patterns.

## Objectives
- Transform sales data into clear and meaningful visualizations.
- Identify high-performing product categories and regions.
- Understand monthly sales trends.
- Compare customer segments and shipping modes.
- Communicate data-driven business insights.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Visualizations
1. Monthly Sales Trend
2. Total Sales by Category
3. Sales by Sub-Category
4. Total Sales by Region
5. Sales by Customer Segment
6. Top 10 Products by Sales
7. Order Records by Shipping Mode
8. Top 10 States by Sales

## Project Structure
- `CodeAlpha_Data_Visualization.ipynb` — Python code and analysis.
- `train.csv` — Dataset, if sharing is permitted.
- `charts\` — Saved visualization images.

## Key Findings
Add the actual findings generated by the notebook, including the leading category, region, customer segment, and product.

## Conclusion
The visualizations help summarize sales performance and highlight areas that may deserve further business investigation.

## How to Run
1. Download or clone the repository.
2. Install the required libraries: pandas, numpy, matplotlib, and seaborn.
3. Place the dataset in the same folder as the notebook.
4. Open the notebook in Jupyter and run the cells in order.
